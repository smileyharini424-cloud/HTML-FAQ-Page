# HTML FAQ Page

## Explanation

This program creates a Frequently Asked Questions webpage using HTML.

It displays common questions and allows users to expand each question to view its answer.

## Problem Statement

Create an HTML FAQ webpage that displays questions and answers in expandable sections.

## Features

- Displays frequently asked questions
- Organizes questions into categories
- Uses expandable sections
- Keeps answers hidden until selected
- Simple and user-friendly structure

## How It Works

The <details> element creates an expandable section.

The <summary> element displays the question that the user can click.

The <p> element contains the answer.

When the user clicks a question the corresponding answer is displayed.

## Technologies Used

- HTML5
- Web Browser

## HTML Tags Used

- <details> - Creates expandable content
- <summary> - Creates the clickable question
- <h1> - Creates the main heading
- <h2> - Creates category headings
- <p> - Displays answers
